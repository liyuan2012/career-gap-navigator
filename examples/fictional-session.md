# Fictional walk-through: stage gates and answer interpretation

> This is a **synthetic logic demonstration**, with no real candidate,
> institution, opportunity, funding body or course. It does not provide
> evidence for real applications. It contains **no preset target city or job**.

**Participant**: uploads a CV but no goal information.

**Assistant**: asks for exactly the missing essentials, then stops:

> Target occupation:
> Preferred location: (remote/host scope if relevant)
> Target level: (entry-level / mid-level / senior / career changer / unsure)

**Participant**: supplies their own target, location and level, optionally
requesting a **fellowship or research funding programme**. The assistant does
not invent a job goal from the participant's CV.

**Assistant Stage 1**: looks up accessible real opportunities of the **types
explicitly requested**; if funding is requested, checks actual host/category,
mandatory eligibility and competitive selection criteria independently. It
records links and checked dates, creates source-linked R-IDs, explains every
classification and asks 3–5 questions, each testing **one coherent uncertainty**.
It then **STOPS**; there is no premature training plan.

**Participant**: says 'yes' to having assisted with a completed activity, but
supplies no scope, date or independent evidence. They also say they have
**never operated** another process.

**Assistant Stage 2**: records each response as `SELF-REPORTED`, does not turn
'assisted' into ownership, and does not turn 'never operated' into a confirmed
skill deficit. In the Change Log it explains **both changes and retentions** for
the R-IDs addressed by these answers. It still shows every R-ID in the revised
summary. Only justified priorities yield courses or training paths. It provides
a realistic 30/60/90-day roadmap and near-term actions.

**Remember**: the example intentionally contains no real vacancy, funding call,
course price, employer or personal CV details. Never use hypothetical values as
source evidence for a real user.
