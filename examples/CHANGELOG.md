# Changes to Career Gap Navigator

This log uses functional stage descriptions rather than internal prompt version
numbers, so readers can follow the project design without knowing its test IDs.

## Multilingual documentation

- Kept `README.md` as the English GitHub landing page and added complete
  Simplified Chinese (`README.zh-CN.md`) and Finnish (`README.fi.md`) guides.
- Added reciprocal language-switching links at the top of all three README files.
- Kept technical classification labels, source links, privacy safeguards,
  pilot limitations and usage instructions aligned across languages.
- Expanded structural checks to validate all localized README links.
- The core `SKILL.md` and standalone prompt remain unchanged by this documentation update.

## Current Skill upgrade

- Replaced the standalone prompt with the participant's updated prompt **without
  changing its substantive wording**.
- Made employment the default; fellowship, research funding, scholarships and
  other programmes are included **only when explicitly requested**.
- Added source categories and eligibility/selection-criterion distinctions for
  research funding and other non-employment opportunities.
- Strengthened minimum intake requirements, multilingual parity and per-R-ID
  evidence rationales.
- Prevented Stage 1 questions from bundling independent competencies; ensured
  short yes/no answers are interpreted within the precise question scope.
- Required Stage 2 to log **reasoned label retentions**, not just changes, and
  to keep a full revised R-ID table with provenance and unresolved questions.
- Updated course verification, source dates, costs and enrolment checks, and
  tied roadmap outputs to no more than three priorities.
- Expanded human acceptance scenarios, structural checks and privacy checks.

## Previous design stages

- Initial workflow separated job-side requirements from CV-side evidence.
- Classification refinement clarified knowledge vs completed activity vs
  operational ownership vs missing evidence.
- A limited anonymised same-candidate three-CV comparison showed improved
  consistency from 14 of 18 agreement to 18 of 18 agreement after refinement.
- Follow-up verification, real-source search, learning choices and the personal
  development roadmap were added for the later interactive pilot.

**Limits:** The agreement comparison is **not accuracy validation**; the full
upgraded interaction still needs diverse real-user evaluation.
