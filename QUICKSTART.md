# Career Gap Navigator — Quick Start

**Languages:** [English](#english) | [简体中文](#简体中文) | [Suomi](#suomi)

**Choose one of the following two ways to use Career Gap Navigator.** No coding or job advertisements are needed. For privacy, remove unnecessary personal identifiers from your CV before uploading it to an AI platform.

## English

### Method 1 — Upload CV + paste the full prompt (recommended)

1. Start a **new conversation** with your AI assistant and upload your CV.
2. In the chat, provide your target information using this short template:

   \`\`\`text
   Target occupation:
   Preferred location: (include remote preference if relevant)
   Target level: (entry-level / mid-level / senior / career changer / unsure)
   \`\`\`

3. Open [Career Gap Navigator.txt](Career%20Gap%20Navigator.txt), copy **all** of its contents, and paste them into the same conversation.
4. The assistant should begin **Stage 1**, ask 3–5 verification questions and stop. Answer those questions to receive the revised assessment, learning options and **30/60/90-day plan** in **Stage 2**.

### Method 2 — Upload CV + provide a GitHub link

1. Start a **new conversation**, upload your CV, and send the message below (fill in the target fields):

   \`\`\`text
   Please read the complete "Career Gap Navigator.txt" prompt in this GitHub repository and follow its instructions, including both stages:
   https://github.com/ly2012yanzi-sys/career-gap-navigator

   My CV is attached.
   Target occupation:
   Preferred location:
   Target level:

   If you cannot open or read the complete prompt file, tell me before starting the assessment.
   \`\`\`

2. If your AI platform can access the repository, it can read and follow the prompt. If the platform cannot access the link or read the full file, **use Method 1** instead.

**Important:** Pasting a GitHub link alone does **not** automatically install an Agent Skill or guarantee that an AI assistant has read the prompt. A platform with supported GitHub/browser access is required for Method 2. You can also provide the [direct prompt-file link](Career%20Gap%20Navigator.txt).

**Missing details?** The assistant should ask for any missing CV, target occupation, preferred location or target level **before** searching. The AI searches for real job advertisements itself when browsing is available; supplying advertisements is optional.

## 简体中文

### 方法一：上传 CV + 粘贴完整提示词（推荐）

1. 在 AI 平台中打开**新对话**，上传自己的 CV（建议先删除不必要的个人身份信息）。
2. 在聊天中填写以下信息：

   \`\`\`text
   Target occupation: 目标职业或职业方向
   Preferred location: 目标地区（如需要，注明是否接受远程工作）
   Target level: 目标级别（初级 / 中级 / 高级 / 转行 / 不确定）
   \`\`\`

3. 打开 [Career Gap Navigator.txt](Career%20Gap%20Navigator.txt)，**复制全部内容**并粘贴到同一对话。
4. AI 首先进行 **Stage 1**，提出 3–5 个核实问题并暂停；你回答后，AI 才进入 **Stage 2**，给出更新后的差距分析、适当的课程选项及 **30/60/90 天行动计划**。

### 方法二：上传 CV + 提供 GitHub 链接

1. 新开 AI 对话，上传 CV，并发送以下信息（填写目标信息）：

   \`\`\`text
   请读取以下 GitHub 仓库中的完整 "Career Gap Navigator.txt" 提示词，并严格按照它的两个阶段执行：
   https://github.com/ly2012yanzi-sys/career-gap-navigator

   我已上传 CV。
   Target occupation:
   Preferred location:
   Target level:

   如果你不能打开仓库或读取完整提示词，请先告知我，不要自行开始分析。
   \`\`\`

2. 如果 AI 可以访问并读取仓库文件，就可以按提示词开始分析。如果无法读取，**改用方法一**。

**注意：** 仅粘贴 GitHub 地址**不等于自动安装 Skill**，也不能保证 AI 已经读取提示词。方法二需要 AI 平台具备相应的网页或 GitHub 文件访问能力；也可直接提供[提示词文件链接](Career%20Gap%20Navigator.txt)。

**其他说明：** 如果目标职业、地点或级别缺失，AI 应先向你询问；能够联网时，通常无须自行准备招聘广告。

## Suomi

### Tapa 1 — Lataa CV ja liitä koko kehote (suositeltu)

1. Aloita **uusi keskustelu** tekoälypalvelussa ja lataa ansioluettelosi. Poista ensin tarpeettomat henkilötiedot.
2. Ilmoita tavoitteesi seuraavilla kentillä:

   \`\`\`text
   Target occupation: tavoiteammatti tai urasuunta
   Preferred location: tavoitealue (kerro tarvittaessa etätyötoive)
   Target level: ura- tai tehtävätaso (aloittelija / keskitaso / kokenut / alanvaihtaja / epävarma)
   \`\`\`

3. Avaa [Career Gap Navigator.txt](Career%20Gap%20Navigator.txt), kopioi **koko kehote** ja liitä se samaan keskusteluun.
4. Tekoäly tekee ensin **Stage 1** -arvioinnin ja esittää 3–5 tarkentavaa kysymystä. Vastaa kysymyksiin, jotta saat **Stage 2** -vaiheessa päivitetyn arvion, sopivia oppimisvaihtoehtoja sekä **30/60/90 päivän suunnitelman**.

### Tapa 2 — Lataa CV ja anna GitHub-linkki

1. Aloita **uusi keskustelu**, lataa CV ja lähetä seuraava viesti (täydennä tavoitteet):

   \`\`\`text
   Lue tämän GitHub-repositorion "Career Gap Navigator.txt" -kehotetiedosto kokonaan ja noudata sen molempia vaiheita:
   https://github.com/ly2012yanzi-sys/career-gap-navigator

   Olen ladannut CV:ni.
   Target occupation:
   Preferred location:
   Target level:

   Jos et pysty avaamaan tiedostoa tai lukemaan koko kehotetta, kerro siitä ennen analyysin aloittamista.
   \`\`\`

2. Jos tekoälypalvelu pystyy lukemaan GitHub-tiedoston, se voi suorittaa ohjeet. Muussa tapauksessa **käytä tapaa 1**.

**Huomaa:** Pelkkä GitHub-linkin liittäminen **ei asenna Agent Skill -taitoa automaattisesti** eikä takaa, että tekoäly on lukenut kehotteen. Tapa 2 edellyttää palvelulta pääsyä GitHub-tiedostoihin. Voit myös jakaa [suoran kehotetiedoston linkin](Career%20Gap%20Navigator.txt).

**Puuttuvat tiedot:** Jos CV, tavoiteammatti, sijainti tai tavoitetaso puuttuu, tekoälyn tulee pyytää niitä ennen hakua. Työpaikkailmoituksia ei yleensä tarvitse liittää itse, jos palvelussa on verkkohaku käytettävissä.
